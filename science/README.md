# Scientific account

The scientific question is how a known pure target can be certified when every input qubit yields one noisy local report. The main theorem determines the optimal exponential copy rate for distinguishing a generic target from the maximally mixed state. The fidelity-certification consequence identifies the detector-noise scale compatible with polynomial samples.

Read the account in this order:

1. [Model and results](model-and-results.md): promises, allowed measurement strategies, charged resources and the result map.
2. [Uniform concentration](uniform-concentration.md): normalized Gaussian moments, a product-effect net, partial records and a finite-size bound uniform in the noise strength.
3. [Binary sample law](binary-sample-law.md): arbitrary classical feedback and interleaving, the full-transcript hybrid proof, exact Haar moments and the matching fixed-basis test.
4. [Fidelity certification](fidelity-certification.md): the ideal conditional-fidelity observable, known detector-channel inversion, exact-target and robust promises, and the polynomial noise threshold.
5. [Circuit targets](circuit-targets.md): quantitative approximate-design transfer, polynomial preparation cost and supplied inverse control.
6. [Acquisition and control](acquisition-and-control.md): separable measurements after local depolarization, the global typical-error-span test and resources that change the measurement architecture.

The [comparison with existing work](../references/RELATED_WORK.md) gives the scope of the contribution and the [reference list](../references/REFERENCES.md) identifies the primary sources. The [reproduction guide](../code/README.md) states which finite identities are checked and which claims are analytical.
